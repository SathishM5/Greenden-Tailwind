# 🌿 GreenDen – Plant Store Website

## 📌 About the Project
GreenDen is a simple and responsive plant store website created using HTML and Tailwind CSS. It provides a clean and attractive interface to showcase different plants and gardening products.

## 🛠️ Technologies Used
- HTML5
- Tailwind CSS

## ✨ Features
- Home page
- Product collection section
- Responsive navigation bar
- Clean and simple user interface
- Plant product showcase

## 🎯 Project Purpose
This project was developed to improve my frontend development skills and gain practical experience in building websites using HTML and Tailwind CSS.

## 🚀 Future Improvements
- Add JavaScript functionality
- Add shopping cart features
- Improve responsiveness
- Add product search functionality
